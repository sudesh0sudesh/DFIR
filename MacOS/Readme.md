# MacOS DFIR Resources

This directory contains scripts, tools, and documentation related to Digital Forensics and Incident Response (DFIR) for macOS systems.

## Contents

- **Scripts**: Automation tools for collecting forensic artifacts, logs, and system information from macOS devices.
- **Documentation**: Guides and references to assist in macOS forensic investigations.
- **Examples**: Sample output files and usage examples.
