
DFIR Repository
This repository maintains scripts and other documents related to DFIR (Digital Forensics and Incident Response).

Contents
- Playbooks: Contains various playbooks for DFIR activities.
- PowerShell Scripts: Includes PowerShell scripts for detecting and analyzing different scenarios.
- Velociraptor: Contains Velociraptor artifacts for forensic investigations.

How to Contribute
1. Fork the repository.
2. Create a new branch (git checkout -b feature-branch).
3. Commit your changes (git commit -m 'Add new feature').
4. Push to the branch (git push origin feature-branch).
5. Open a Pull Request.
